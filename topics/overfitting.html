Overfitting

A model that is too flexible learns the noise instead of the pattern. It looks perfect on training data and fails on new data.

The setup

The hidden truth is the curve y = sin(2πx). We only see a few measurements of it, each with random noise. We fit a polynomial of degree d by least squares, the same as linear regression but with features 1, x, x², …, xᵈ. Then we check it twice:

  • train error: on the points it was fitted to;
  • test error: on 200 fresh points from the same source that it never saw.

What the chart shows

Train error only goes down as the degree grows: a bigger family of curves can always fit at least as well. Test error makes a U. At first it falls (the model learns the shape), then it shoots up (the model learns the noise). When the number of coefficients reaches the number of points, the curve can pass through every point exactly. Train error drops to almost zero, and the curve between the points goes wild.

The dotted line is the noise level. Even the true curve has this test error, because noise cannot be predicted. A train error below that line is a warning sign: the model has memorized random noise.

A physics picture: systematic and random error

Test error splits into two parts that every experimentalist knows:

  • Bias is systematic error. A straight line cannot bend into a sine wave, no matter how much data you give it. Every repetition of the experiment misses in the same way.
  • Variance is random error. A degree-15 polynomial fits each new sample perfectly, but every sample gives a different crazy curve. The answer depends on the noise you happened to get.

Turn on Show 20 fits. Each thin line is the same model trained on another random sample. The spread of the lines is the variance; the gap between their average (dashed) and the true curve is the bias. Low degree: tight bundle, wrong shape. High degree: right shape on average, huge spread. The best degree balances the two.

Three cures

  • A simpler model: lower the degree.
  • More data: drag "training points" to 60. The same degree now overfits much less, because noise averages out over more measurements.
  • Regularization: the L2 term λ·|w|² punishes huge coefficients. Watch |w|: an overfitted curve needs enormous coefficients that nearly cancel each other out, and the penalty forbids that.
