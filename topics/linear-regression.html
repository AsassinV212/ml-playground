The model

Linear regression predicts a number with a straight line:

ŷ = w · x + b

w is the slope and b the intercept. With many features it becomes ŷ = w₁x₁ + w₂x₂ + … + b, but the idea is the same. Training means choosing w and b so that the predictions miss the data as little as possible.

How do we measure "miss"?

For each point the residual is r = ŷ − y, the vertical gap between the point and the line. A loss turns all the residuals into one number:

  • MSE = average of r². On the plot each squared error is a real square.
  • MAE = average of |r|. On the plot each error is a vertical segment.

A physics picture: springs

Attach every point to the line with a vertical spring. A spring stretched by r stores energy ½kr², so the total energy is proportional to MSE. Let the line go and it settles where the energy is lowest: that is the least-squares fit.

The pull of a spring grows with its stretch. A far-away outlier stretches its spring a lot and drags the whole line towards itself. With MAE every point pulls with the same force no matter how far it is, like a weight hanging on a string over a pulley. One distant point is then just one vote, and the line stays with the majority. Press Outlier and compare.

Two ways to find the minimum

  • Exact. For MSE the minimum has a formula: w = cov(x, y) / var(x), and the line passes through the average point. With many features this is the normal equation w = (XᵀX)⁻¹Xᵀy.
  • Gradient descent. Start with a flat line and roll downhill on the loss, exactly like on the gradient descent page. This works for any loss, including MAE, and for millions of features where inverting XᵀX is too slow.

MAE has a catch: its slope near the minimum is not small, it stays ±1. A fixed step would make the line jitter forever, so for MAE the step shrinks over time.

Try this

  • Press Exact, then Reset line and Run: gradient descent arrives at the same line.
  • Add two outliers. Fit with MSE, then switch to MAE and run again.
  • Raise the learning rate until MSE descent diverges.
