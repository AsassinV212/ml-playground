# Project: ml-playground
Interactive static website that visualizes ML algorithms. Audience: a student learning ML.

## Technical rules
- Pure HTML/CSS/JS. NO external dependencies, no build step, no CDN. Must load fast on mobile Safari (iPhone).
- Dark theme, mobile-first layout, touch-friendly controls.
- Python reference implementations live in python/ (numpy only), readable, with pytest tests.
- Small commits with clear messages.

## Language rules
- Everything in the repository is in English: code, comments, commit messages, UI text, README.md.
- Exception: the site has a RU/EN toggle. UI text is authored in English in the HTML; Russian translations
  live only in dictionary files (assets/ru-common.js, topics/*.ru.js). See docs/adding-a-topic.md.
- README.ru.md is a short Russian version of the README.
- In chat with me, always reply in Russian.

## How to work with me
- I'm still learning this material. After each change, explain in simple Russian what you did and why.
- Use analogies from physics when explaining ML concepts.
- Don't just give me finished code: point out the key lines that carry the idea.
